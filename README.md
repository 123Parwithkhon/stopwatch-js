A sleek, responsive, and modern **Stopwatch** web application built with HTML5, CSS3, and Vanilla JavaScript. Features precise time tracking down to milliseconds with an elegant dark mode design.

🔗 **[View Live Demo](https://123parwithkhon.github.io/stopwatch-js/)** *(доступно после включения GitHub Pages)*

---

## ✨ Features
- **Precise Tracking:** Measures hours, minutes, seconds, and milliseconds accurately.
- **Full Control Panel:** Intuitive **Start**, **Pause**, and **Reset** actions.
- **Modern Dark UI:** Styled with a sleek dark theme, striking blue gradients, shadows, and monospaced typography for digital clock consistency (`Roboto Mono`).
- **Responsive Layout:** Centered, flexible card design adapted for various screen sizes.

---

## 🛠️ Tech Stack & Concepts Applied
- **HTML5:** Semantic structural layout and modern font integrations.
- **CSS3:** Custom gradients, box-shadow effects, CSS Flexbox, and absolute positioning.
- **Vanilla JavaScript (DOM & Timing Events):**
  - Timer intervals (`setInterval`, `clearInterval`).
  - Event listeners for user interactions.
  - State management for hours, minutes, seconds, and milliseconds.
  - Dynamic template literals for zero-padding formatting (`00 : 00 : 00 : 000`).
